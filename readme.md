# 🌍 Discover Amazing Places

A modern, responsive travel website created as the **Final Project** for the Coursera **Introduction to CSS3** course.

This project showcases beautiful travel destinations using modern HTML5 and CSS3 techniques while following accessibility and responsive web design best practices.

---

## 📸 Preview

Explore some of the world's most beautiful destinations including:

- 🏔 Swiss Alps
- 🏝 Maldives
- 🌲 Black Forest
- 💦 Iguazu Falls
- 🏞 Moraine Lake
- 🏜 Sahara Desert

---

## 🚀 Features

- ✅ Three responsive web pages
- ✅ Accessible "Skip to Main Content" link
- ✅ Modern navigation bar using Flexbox
- ✅ Responsive image gallery using CSS Grid
- ✅ Hover animations and transitions
- ✅ CSS Box Model styling
- ✅ `nth-child()` selector implementation
- ✅ Semantic HTML5 elements
- ✅ Mobile-friendly responsive design
- ✅ Accessible image alt text
- ✅ Clean and modern travel-inspired interface
